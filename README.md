# 💎 Diamond Portal

A simple, clean diamond inventory management system with Admin and Customer panels.

## Features

### Admin Panel
- Edit company information (name, tax ID, country, email, phone, address)
- Auto-save with Supabase integration
- Reset to default values

### Customer Panel
- Visual diamond inventory with images
- Individual status management (Confirm, Hold, Release)
- Bulk actions (select multiple diamonds and update status)
- Clean, responsive white theme
